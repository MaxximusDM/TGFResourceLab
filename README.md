# TGFResourceLab

Resource calculator and event calendar for **The Godfather: Family Dynasty** players.

## 🚀 Live app

👉 **https://tgfresourcelab.streamlit.app**

## Features

- Resource calculator
- Event calendar

## Run locally

```bash
pip install -r requirements.txt
streamlit run app.py
```
